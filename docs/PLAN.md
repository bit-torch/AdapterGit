# AdapterGit 开发计划

## 项目目标

AdapterGit (agit) 是一个专为 AI 时代设计的 Git 工具，完全从底层用 Rust 原生实现 Git 核心协议和算法。

### 核心价值

- 🤖 **AI 优先**: 零 TUI 阻塞，结构化输出，AI Agent 安全调用
- 📦 **双版本分发**: Full 安装包 + Lite 单文件便携，同一套原生 Git 内核
- 🔒 **安全防护**: 危险操作拦截，防止 AI 误操作
- ⚡ **永不卡死**: 自动跳过编辑器，非 TTY 环境友好

#### Full 版本特性
- 安装包一键安装，注册 PATH、右键菜单、文件关联
- 适用于个人开发机、企业批量部署
- 安装包体积 ~20MB

#### Lite 版本特性
- 单文件便携，下载即用，无需安装
- 纯绿色运行，无系统痕迹
- 适用于 AI Agent、CI/CD、Docker、U 盘携带
- 单文件体积 ~10MB

> **两个版本共享同一套纯 Rust 实现的 Git 核心**（SHA-1、zlib、Blob/Tree/Commit 对象、引用系统、索引、网络协议），仅分发形态不同。

## 技术决策

### 依赖库选择

| 库 | 用途 | 决策 |
|----|------|------|
| `sha1` | SHA-1 哈希 | ✅ 使用 crate |
| `flate2` | zlib 压缩 | ✅ 使用 crate |
| `clap` | CLI 解析 | ✅ 使用 crate |
| `serde` | 序列化 | ✅ 使用 crate |
| `anyhow` | 错误处理 | ✅ 使用 crate |

### 不使用的技术

- ❌ gitoxide (gix) - 纯原生实现
- ❌ 系统 git 命令 - 自己实现
- ❌ 外部 Git 库
